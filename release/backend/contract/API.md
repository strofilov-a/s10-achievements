# API достижений

Один файл на сервере: `/apiweb/achievements.php`. Стиль тот же, что у `userparam.php`: чтение — `GET ?action=…`, запись — `POST` с FormData, где есть поле `action`. Пользователь берётся из cookie сессии, как в остальных `/apiweb/*.php`.

Сервер отдаёт уже посчитанные значения: уровни, даты, очки и звание. Тексты вроде «4 212 из 5 000 км» собирает страница из `value`, `thresholds`, `unit` и `format`. Серверу форматировать числа не нужно. Готовые подписи карточек лежат в каталоге (`card_number`, `card_text`).

Примеры ответов на каждое состояние лежат в [`mock/`](mock). Это одновременно данные демо-страницы и эталон для тестов бэкенда.

## Чтение

| Запрос | Что отдаёт | Пример |
| --- | --- | --- |
| `GET ?action=athlete&id=ID` | Страница достижений атлета. Без `id` — свои | `athlete-normal.json`, `-new`, `-friend`, `-levelup`, `-rankup` |
| `GET ?action=coach&id=ID` | Страница достижений тренера. Без `id` — свои | `coach-normal.json`, `-few`, `-empty`, `-public`, `-levelup`, `-rankup` |
| `GET ?action=widget&id=ID` | Блок в профиле атлета: звание, шкала, витрина | `athlete-profile.json` |
| `GET ?action=coach_widget&id=ID` | Блок в профиле тренера: звание, шкала, три сильные стороны | `coach-profile.json` |

Если смотреть нельзя (владелец выбрал «Только я», или «Подписчики», а смотрящий не подписан), ответ `403` и тело `{"hidden": true, "user": {...}}` или `{"hidden": true, "coach": {...}}`. Примеры: `athlete-hidden.json`, `coach-hidden.json`. Не залогинен: `401`, тело `null`.

### Общие поля ответа

| Поле | Что это |
| --- | --- |
| `now` | Сегодня по Москве, `YYYY-MM-DD` |
| `viewer` | Кто смотрит: `self` — владелец; `friend` — другой атлет; `public` — чужой человек на странице тренера |
| `user` / `coach` | `{id, name, initials}`, у тренера ещё `students` — сколько учеников сейчас |
| `levels` | Названия и очки уровней: `tiers[8]`, `one` («Получено»), `legend` («Легендарное») |
| `ranks` | Звания `[{name, from}]`: у атлета атлетские, у тренера тренерские |
| `categories` | Категории каталога `[{id, name}]` в порядке показа |
| `points`, `rank` | Очки и индекс звания в `ranks` |
| `items` | Достижения: запись каталога плюс прогресс этого пользователя (ниже) |

### Достижение в `items`

Запись каталога (`catalog/athlete.json` или `catalog/coach.json`) как есть, плюс:

| Поле | Что это |
| --- | --- |
| `value` | Текущее значение: км, секунды, место, проценты. `null`, если результата ещё нет. У чужого (`viewer` не `self`) всегда `null` |
| `dates` | Дата каждого полученного уровня по порядку. **Уровень = `dates.length`.** Уровни не отнимаются, даже если `value` потом упало |
| `last` | Необязательно. Подпись последнего уровня, например «18:58, Сидней, 15.02.2026» |
| `note` | Необязательно, только для владельца. Подсказка, например «Тренер не выбран» |
| `rarity` | У скольких процентов пользователей есть каждый уровень (считается ночью) |

Только у тренера:

| Поле | Что это |
| --- | --- |
| `data` | Сколько данных за значением: `{n}` — их число в единицах `data_unit`, `x` — сколько из них «удачных» (для долей), `v` — значение, если это не доля (время ответа, средний процент) |
| `infinite` | `true`, если у «Удержания» никто не ушёл (тогда `value: null`) |
| `count`, `holders` | Счётчик на плашке «Саб 3» и список учеников за ним `[{name, time, date, left?}]`. `holders` видит только сам тренер |

Закрытое секретное достижение уходит без названия, условия и настоящего id: `{"id": "s_1", "kind": "secret", "category": "secret", "locked": true, "rarity": [1.2]}`. Id каждый раз один и тот же для этого пользователя, но по нему нельзя узнать, что за достижение.

Достижения, у которых в каталоге `enabled: false` (данных пока нет), сервер не отдаёт.

### Только для владельца (`viewer: self`)

| Поле | Что это |
| --- | --- |
| `showcase` | Атлет: до 3 id достижений на витрине. Тренер: до 6 карточек учеников (см. «Карточка ученика») |
| `events` | Последние 30 полученных уровней, новые первыми: `{id, achievement, level, date, celebrated}`. `celebrated: false` — окно поздравления ещё не показывали |
| `rank_events` | Полученные звания, новые первыми: `{id, rank, date, celebrated}` |
| `visibility` | Кто видит: атлет `{audience: all \| subs \| me}`, тренер `{audience: all \| students \| me}` |
| `coach` (атлет) | Тренер атлета и статус согласия на показ: `{id, name, initials, consent: pending \| yes \| no}`. `null`, если тренера нет |
| `notifications` | Колокольчик. Типы ниже |
| `students` (тренер) | Ученики: `{id, name, initials, months, rank, points, consent, near, page?, achievements: [карточка ученика]}` |
| `gates` (тренер) | Правило подтверждения уровня данными: `{base: {rep: 20, …}, step: [1,1,1,2,4,6,8,10]}` |
| `athlete_ranks` (тренер) | Атлетские звания, чтобы нарисовать звание ученика |

У чужого атлета (`friend`) есть `items` без значений и `showcase`. У тренера глазами атлета (`public`) есть только сильные стороны: до 5 полученных достижений от Золота и выше, легендарные первыми, и витрина учеников (только с согласия учеников).

### Карточка ученика

`{key, athlete_id, athlete_name, achievement, name, kind, level, number, text, date}`. `number` и `text` берутся из `card_number[level-1]` и `card_text[level-1]` атлетского каталога. `athlete_name` пишется в том формате, который выбрал ученик. `key` — устойчивый id пары «ученик + достижение».

### Уведомления

| `type` | Поля | Кому |
| --- | --- | --- |
| `level` | `event, achievement, level, date` | атлету и тренеру |
| `rank` | `rank, date` | атлету и тренеру |
| `consent_request` | `coach {id, name, initials}, date` | атлету: тренер просит показывать достижения |
| `consent_answer` | `athlete {id, name, initials}, answer: yes \| no, date` | тренеру |
| `consent_pending` | `athlete {...}, date` | тренеру: запрос отправлен, ответа нет |
| `student_level` | `card` (карточка ученика), `date` | тренеру |
| `counter` | `achievement, count, name, time, date` | тренеру: «Саб 3: теперь 3×» |

У всех есть `id` и `unread`.

## Запись

`POST /apiweb/achievements.php`, FormData. Ответ `{"ok": true}` или `{"ok": false, "error": "…"}` с кодом 400/403.

| `action` | Поля | Что делает |
| --- | --- | --- |
| `showcase` | `ids` — JSON-массив до 3 id | Витрина атлета. Только полученные достижения |
| `visibility` | `audience` = `all` \| `subs` \| `me` | Кто видит достижения атлета |
| `consent` | `answer` = `yes` \| `no` | Ответ атлета на запрос тренера. `no` сразу убирает карточки атлета из витрины тренера |
| `coach_showcase` | `keys` — JSON-массив до 6 `key` | Витрина тренера. Пары без согласия ученика отклоняются |
| `coach_visibility` | `audience` = `all` \| `students` \| `me` | Кто видит достижения тренера |
| `consent_request` | `athlete` | Тренер просит ученика. Повтор после отказа — не раньше чем через 30 дней |
| `celebrated` | `events`, `rank_events` — JSON-массивы id | Окна поздравления показаны, больше не показывать |
| `seen` | `notifications` — JSON-массив id | Колокольчик открыт: эти уведомления прочитаны |
