# Достижения и звания S10 · фронтенд · релиз {{release}}

Страница достижений атлета, страница достижений тренера и блок «Достижения» в профиле. Всё уже написано и проверено: это один JS-файл без зависимостей и без сборки, как `/t5/solo/solo.js` у «Моей недели». Данные берутся из `/apiweb/achievements.php`, его ставит бэкенд по своему архиву.

Как это выглядит во всех состояниях: https://strofilov-a.github.io/s10-achievements/ (переключатель внизу слева). Это тот же код на примерных данных.

## Что сделать

1. Положить `t5/achievements/achievements.js` на сервер как `/t5/achievements/achievements.js`.
2. Добавить два маршрута, оба отдают `achievements.html` так же, как сейчас отдаются `/calc3` и `/solo/plan`:
   - `/achievements/athlete` — достижения атлета. Свои без параметров, чужие — `?id=ID`.
   - `/achievements/coach` — достижения тренера. Свои без параметров, чужие — `?id=ID`.

   Отдавать с заголовком `Cache-Control: no-cache`, чтобы новая версия приходила сразу.
3. В профиль атлета (`/profile?ID`) между данными атлета и «Планами» вставить:

   ```html
   <div data-s10-achievements="widget" data-id="ID"></div>
   ```

   В профиль тренера на то же место:

   ```html
   <div data-s10-achievements="coach-widget" data-id="ID"></div>
   ```

   Вместо `ID` — id профиля, который открыт. На странице профиля один раз подключить скрипт:

   ```html
   <script src="/t5/achievements/achievements.js?v={{release}}" defer></script>
   ```

   Скрипт сам находит эти блоки, даже если React нарисует их позже, и рисует внутри них. Высоту блок берёт сам. Если достижения скрыты владельцем или сервер не ответил, блок остаётся пустым и профиль работает как раньше.
4. Добавить в меню сайта пункт «Достижения» со ссылкой на `/achievements/athlete`. Тренерам ещё пункт «Достижения тренера» со ссылкой на `/achievements/coach`.

Больше ничего не нужно: ни сборки, ни React-компонентов, ни правок стилей. Страница рисуется в своём Shadow DOM, поэтому стили сайта её не задевают, а её стили не задевают сайт. Шапка с меню S10 такая же, как у «Моей недели».

## Проверка

Когда бэкенд уже на тестовом сервере:

1. `/achievements/athlete` под атлетом с историей: звание, «На подходе», витрина, последние полученные, все достижения. Клик по карточке открывает окно с 8 уровнями.
2. Закрепить достижение в витрине, обновить страницу: оно на месте.
3. «Кто видит» → «Только я». Открыть ту же страницу под другим пользователем с `?id=` — «скрывает свои достижения».
4. `/achievements/coach` под тренером: звание, ученики, витрина учеников, «Изменить».
5. Профиль атлета и тренера: блок «Достижения» на месте, ссылка «Все достижения» ведёт на страницу.
6. То же на телефоне.

Когда всё на месте, напишите нам: мы проверим сами.
